# Luz en Movimiento — sitio demostrativo

Sitio web multipágina para una organización dedicada a personas ciegas y con baja visión.

## Abrir el sitio

Abre `index.html` en un navegador. No requiere instalación, compilación ni conexión a internet.

## Páginas

- `index.html`: inicio y resumen de impacto.
- `quienes-somos.html`: misión, visión, valores y equipo.
- `proyectos.html`: proyectos realizados con filtros interactivos.
- `transparencia.html`: uso ilustrativo de recursos y rendición de cuentas.
- `sumate.html`: simulador de impacto, donativo y formulario de contacto.

## Antes de publicar

Todo nombre, cifra, testimonio, dato de contacto y documento es ficticio. Sustituye el contenido por datos verificados de la organización real y conecta el formulario y el botón de donación con servicios seguros.

La imagen de portada fue generada especialmente para este proyecto con la herramienta integrada de generación de imágenes.
